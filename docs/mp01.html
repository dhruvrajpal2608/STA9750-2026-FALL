1,2. Data Acquisition & Recreating the Columns

For Data acquisition from the Netflix server, below script can be executed to load the data from 2023 to 1st half of 2026 with 7 CSV files, in the local environment with a more personalized approach to benefit the Data manipulation and EDA.

load_netflix_data <- function(){

  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 7, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event) |>
    
  rename(title = Title,
         runtime = 'Runtime',
         views = 'Views',
         hours_viewed = 'Hours Viewed',
         release_date = 'Release Date',
         available_globally = 'Available Globally?')
}

  • Within each period, what fraction of time was spent on ‘shows’ vs movies?

To solve the query for watch time spent on TV Shows and Movies within each period. We start by defining and classifying TV Shows and Movies i.e. content having more than runtime of 210 minutes (3.5 hours) is a TV show and titles with runtime between 40 and 210 minutes is a Movie.

tv_pattern <- regex(
  '\\b(Season|Series|Part|Volume|Vol\\.|Chapter|Episode|Episodes|Limited Series|Miniseries|Collection)\\b', ignore_case = TRUE
)

class_netflix <- NETFLIX_DATA |>
  mutate(
    content_type = case_when(
      str_detect(title, tv_pattern) ~ "TV Show",
      runtime > 210 ~ "TV Show",
      runtime >= 40 & runtime <= 210 ~ "Movie",
      runtime > 180 ~ "TV Show",
      TRUE ~ "Movie"
    )
  )
content_type_summary <- class_netflix |>
  summarise(
    viewed_hours = sum(hours_viewed, na.rm = TRUE),
    type_runtime = sum(runtime, na.rm = TRUE) / 60,
    n_titles = n_distinct(title),
    .by = c(period, content_type)
  ) |>
  mutate(
    period_total_runtime = sum(viewed_hours, na.rm = TRUE),
    watch_pattern = viewed_hours / period_total_runtime,
    share = percent(watch_pattern, accuracy = 0.1),
    .by = period
  ) |>
  arrange(period, content_type)

How does the performance of live events compare to pre-taped content? Does the average live event draw more viewership than an average piece of pre-taped content? How about a ‘top tier’ live event vs ‘top tier’ pre-taped content?

By computing Average Viewed hours average_hours for Live Events and Pre taped content, certainly Pre taped content draw more viewership in average watch-time than that of Taped content.Also, we can observe same pattern while comparing the Top_tier segment of both the classes.

average_comp <- NETFLIX_DATA |>
  summarise(
    n_titles = n(),
    average_hours = mean(hours_viewed, na.rm = TRUE),
    medi_hours = median(hours_viewed, na.rm = TRUE),
    average_views = mean(views, na.rm = TRUE),

  mutate(

    across(c(average_hours, medi_hours, average_views, medi_views), comma)

Corporate Strategy Memo

To: Netflix Executive Leadership FROM: Dhruv Rajpal (Business Analyst) SUBJECT: Data-Driven Strategic Directives for Original Content (2027 & Onward)

Executive Summary

Analysis of semi-annual What We Watched engagement data across the 2023–2026 reporting cycles reveals structural insights into subscriber viewing patterns. Total platform consumption has leveled at roughly 90 to 95 billion hours per half-year, indicating that future growth must focus on capital retention efficiency and catalog monetization rather than raw volume expansion.

To maximize ROI on 2027 production budgets, I recommend allocating development capital around three core data realities: 1. The Structural Primacy of Multi-Episode TV Series over standalone feature films.

  1. The Enduring Dominance of the Catalog Long-Tail over top-tier tentpoles.

  2. The High-Efficiency “Eventization” of Live Shows/ Games to solve franchise decay.

  3. Enrichment in UI/ UX for Netflix Games and remote controller connectivity.

  4. Investment on better recommendation engines with Machine Learning Algorithms.

Key Empirical Findings

  1. Series vs. Feature Films: Hours vs. Reach

Across consistent reporting periods, TV Shows and OTT Series captures approximately 72% of total viewing hours, while feature films account for only 28% (e.g., 67.2B hours vs. 26.2B hours in 2023H1).

The Aggregate Run-time Advantage: A feature film offers 90 to 120 minutes of engagement per converted subscriber, whereas a standard 8-to-10 episode series demands average 300- 400 minutes of watch time.

Subscriber Value Retention: Standalone feature films frequently top initial weekly view counts, but episodic series drive repeat weekly sessions and minimize subscriber churn through multi-week sustained watch time.

  1. Concentration Dynamics: The Top 10 vs. The Catalog Long-Tail

Despite heavy marketing investments in premier intellectual property, viewership remains distributed across a vast library:

Title Ceiling: The single most-watched title in any 6-month period never captures more than 0.62% to 0.87% of total viewing time (e.g., The Night Agent: S1 captured 812.1M hours, or 0.87% in 2023H1; Fool Me Once captured 583.0M hours, or 0.62% in 2024H1).

Top 10 Aggregate Share: In any single half-year cycle (such as 2026H1), the Top 10 titles collectively generate between 2.8% and 3.4% of total hours viewed. Over 96% of all platform consumption occurs across the remaining catalog long-tail and established comfort-viewing staples (Suits, Gilmore Girls, Cocomelon).

  1. Live Broadcasts vs. Pre-Taped Originals

Live events (e.g., marquee roasts, sports exhibitions, comedy specials) account for fewer than 0.2% of all distinct catalog entries, yet they deliver distinct structural benefits:

Elevated Floor: Because live events are curated tentpoles, the average live event generates over 2.8× the mean viewership hours of the median pre-taped catalog release.

Peak Volume Trade-off: Top-tier live events peak between 20M and 65M hours, compared to 500M+ hours for premier episodic dramas like Bridgerton or Stranger Things. Live events drive acute sign-up bursts and cultural buzz, while pre-taped series build sustained, multi-year asset value

Strategic Recommendations for 2027 and Beyond

Re balance the Slate Toward Returnable, Multi-Season TV (70/30 Budget Split):

Re-allocate film acquisition budgets toward developing recurring multi-season mid-budget procedural dramas and light comedies. Given that television generates ~72% of platform watch time, standalone $150M+ action films provide limited long-term retention compared to an established episodic universe.

De-escalate Megahit Spending; Invest in Catalog Anchors:

Because the Top 10 accounts for ~3% of platform hours, no individual mega-budget release can sustain user engagement alone. Redirect development funds toward acquiring and commissioning multi-year “comfort food” series (such as unscripted documentaries, workplace dromedaries, and kids/family animation) that maintain viewership floors above 15M hours across every reporting window.

Deploy Live Events Strategically as Churn Breakers, Not Runtime Engines:

Treat live sports, comedy specials, and reunions as customer-acquisition spikes rather than total watch-time drivers. Schedule live broadcasts strategically at the beginning of billing cycles to precede major season releases of high-engagement scripted dramas.

Conclusion

Our competitive advantage in 2027 will not come from outspending rivals on high-risk, single-weekend blockbusters. By leveraging OTT series for baseline engagement and deploying high-impact live events for subscriber acquisition, Netflix can expand operating margins while reinforcing viewer retention.
